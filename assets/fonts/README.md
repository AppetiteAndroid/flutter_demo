# Gilroy and Cera Round

These commercial fonts are intentionally not bundled. The starter uses the
platform font so clean clones compile. With appropriate licenses, add Gilroy
files under `assets/fonts/gilroy/` and Cera Round files under
`assets/fonts/cera_round/`, declare their exact filenames and weights in
`pubspec.yaml`, then set the corresponding family in `AppTypography`. Never
commit font binaries unless the license explicitly permits redistribution.
