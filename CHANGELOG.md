# Changelog

All notable template changes follow Semantic Versioning.

## 1.0.0 — 2026-08-23

- Stabilized and documented public extension points and long-lived ownership.
- Added deterministic translation, dependency/license, secret, fresh-copy and
  end-to-end rename verification.
- Hardened production logging, dependency disposal, accessibility and adaptive
  large-text behavior.
- Pinned the release Flutter SDK and hardened Android/iOS CI and artifacts.
- Added GitHub Template metadata, release gates, QA/performance/security/privacy
  documentation, migration notes and post-v1 roadmap.

## 0.3.0

- Added Drift local data, transactional outbox, serialized sync engine,
  reachability, lifecycle, authenticated realtime and background-sync recipes.

## 0.2.0

- Added native flavors, typed links/notifications, observability adapters,
  feature flags, pagination, branding validation and feature generation.

## 0.1.0

- Added runnable architecture, configuration, DI, design system, localization,
  settings, reactive search, session, secure tokens, networking and routing.
