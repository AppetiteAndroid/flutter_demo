# Flutter Production Starter v1.0.0

The first stable template release preserves the v0.1 foundation, v0.2 native
integrations and v0.3 offline/realtime reference while making setup and rename
repeatable. It adds release audits, isolated template-copy verification,
accessibility/adaptive hardening, pinned CI, security/privacy ownership guidance
and GitHub Template metadata.

No backend, Firebase account, commercial font, signing credential or production
secret is required. Review `KNOWN_LIMITATIONS.md` and complete owner-only
license/security/template settings before publication.
