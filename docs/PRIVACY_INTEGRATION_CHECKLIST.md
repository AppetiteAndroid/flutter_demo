# Privacy integration checklist

- [ ] Inventory personal/sensitive data and document purpose/retention.
- [ ] Keep credentials in secure storage and out of snapshots/logs.
- [ ] Decide logout erasure policy (template demo rows are erased).
- [ ] Configure OS backup/data-protection for the product data class.
- [ ] Request permissions only after contextual user action.
- [ ] Treat push/link payloads as untrusted identifiers.
- [ ] Gate analytics on consent and support identity reset/deletion.
- [ ] Review crash attachments/breadcrumbs for PII.
- [ ] Validate subscriptions with the store/server, not cached access.
- [ ] Publish privacy and vendor/subprocessor disclosures.
- [ ] Exercise switch, deletion, export and offline retention behavior.
