# Accessibility and adaptive QA

Automated widget tests cover semantic labels, control roles, minimum 48×48
targets, Light/Dark themes, a 320 logical-pixel viewport and 200% text. Lists
scroll, SafeArea protects system UI, the offline composer stacks on narrow or
large-text layouts, and skeleton animation respects reduced motion. Statuses
combine icons, localized text and semantics rather than color alone.

Before a product release manually exercise every screen with TalkBack and
VoiceOver: order, names/values, dialog focus, live sync status, keyboard focus,
200–300% text, bold text, reduced motion, Light/Dark, portrait/landscape,
smallest phone and gesture/three-button Android navigation. Never disable text
scaling to satisfy screenshots.
