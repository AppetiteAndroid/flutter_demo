# Post-v1 roadmap

- Migrate deferred major plugin releases with native regression tests.
- Add optional device integration automation without live services.
- Exercise maintained near-minimum Android/iOS runtimes in scheduled QA.
- Add optional encrypted-database and product backup-policy recipes.
- Add vendor adapters only after an application chooses a vendor.
- Expand locales/formatting through `intl` when product requirements justify it.
- Add release provenance/SBOM after hosting policy is selected.

These are not current v1.0 behaviors or promises.
