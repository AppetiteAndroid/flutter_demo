# Security policy

Do not open a public issue containing a vulnerability, credential, private
endpoint, user data, or exploit details. Use GitHub Private Vulnerability
Reporting when the repository owner has enabled it. Until the owner configures
that channel, the repository intentionally publishes no fabricated security
email or response-time promise.

Supported release policy and integration responsibilities are documented in
[`docs/SECURITY.md`](docs/SECURITY.md). The owner must configure and publish a
real contact before enabling the repository as a public template.
